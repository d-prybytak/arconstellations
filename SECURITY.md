# Security

Zenith is a client-side planetarium. It does not store accounts or payments.

If you find a vulnerability (XSS on the HUD, a supply-chain issue in
dependencies, anything that could run untrusted code in WebXR):

1. **Do not** open a public issue.
2. Report it privately via [GitHub Security Advisories](https://github.com/d-prybytak/AR-Constellations/security/advisories/new).

Please include the affected file, a short reproduction, and the browser or
headset. We will answer as soon as we can.
