# Zenith

Держи небо.

Веб-планетарий для iPhone, Android, Galaxy XR и браузера. Снаружи свод
совпадает с горизонтом. В комнате это полная сфера, которую можно повернуть
рукой. Нажми на фигуру — она собирается из ночи и встаёт перед тобой.

Репозиторий на GitHub называется `AR-Constellations`. Продукт — **Zenith**,
не proof of concept.

Полная документация, запуск и архитектура — в английском [README.md](README.md).
Issues и pull request можно писать по-русски.

## Зачем открытый код

Небо — общие данные. Hipparcos, фигуры IAU, планеты этого часа не должны
жить за логином. Интересная работа — сделать так, чтобы каталог было *видно*:
телефон как окно, очки, в которых Орион стоит в комнате, фигура, которая
прилетает, когда её зовут.

Это длинный проект. Звёзды, миф, туманности, спутники, вспышки, тёмное небо,
переводы, нативные оболочки. Он больше одного человека.

Небо остаётся бесплатным. Если позже появится founding pass, он будет кормить
хостинг и искусство — не запирать звёзды.

## Сейчас умеет

- Телефон: **Hold to the sky** — гироскоп и компас ведут свод
- Desktop: тяни взгляд, pinch/скролл — зум
- Galaxy XR: WebXR `immersive-ar`
- Outdoor / indoor, Atlas / Place / Night / Chart
- 5 044 звезды Hipparcos до 6m, 88 фигур IAU, Солнце, Луна, планеты
- Gather: созвездие выходит из свода и встаёт перед тобой
